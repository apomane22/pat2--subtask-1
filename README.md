# Morse Code Research - Subtask 1

## Overview of Morse code
Morse code is a system used to send messages using two different signal lengths: dots and dashes. It was one of the first ways people could send digital messages using sound, light, or electricity.

## History
It was created in the 1830s by Samuel Morse and Alfred Vail. They designed it specifically for the electric telegraph. This was important because it let people communicate over long distances much faster than sending a letter by hand.

## How the system works
The code is based on the timing of the signals:
*   A dot is the shortest signal.
*   A dash is longer (equal to 3 dots).
*   Letters are separated by a short gap.
*   Words are separated by a longer gap.
